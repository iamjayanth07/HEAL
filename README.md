# 🩸 Blood Report Health Condition Predictor

This project is a machine learning-powered web application that analyzes blood report values and predicts possible health conditions.

### 🔍 Features
- Users can input common blood report values such as:
  - Hemoglobin, Sugar, Cholesterol, Iron, Vitamin D
  - Platelets, WBC Count, RBC Count, Creatinine, Uric Acid
- The system predicts potential health issues like:
  - Anemia, Diabetes, Vitamin D Deficiency or Toxicity
  - Cholesterol Imbalance, Kidney Issues, and more
- Built with:
  - 🧠 Machine Learning (Random Forest + MultiOutputClassifier)
  - 🌐 Flask Web Framework
  - 📊 Trained model with real patterns (normal, high, low, borderline)
  - Front End:HTML ,CSS,BOOTSTRAP
